# ATLAS XR AI Assistant

This repository contains two versions of the standalone XR AI Assistant I developed during my ATLAS internship. It combines a head-following display, hand gestures, speech, camera capture, captions and navigation. In a separate internship project, I integrated the assistant into the team's existing VR Quad Games environment.

| Unity Editor | Project | Starting point |
| --- | --- | --- |
| `6000.3.15f1` | [Standalone XR Assistant](./XR_AI_Assistant_6000_3_15/) | Follow the [package restore and setup instructions](./XR_AI_Assistant_6000_3_15/README.md#open-the-project), then open `Assets/Scenes/UI Quest Display.unity`. |
| `6000.0.41f1` | [Original prototype](./XR_AI_Assistant-main/) | Use this folder to open the spring 2026 version with its original Editor. |
